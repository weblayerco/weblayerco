# نور · Noor

تطبيق لتعليم الأطفال (خاصة أبناء المغتربين) **نطق الحروف العربية** نطقاً صحيحاً،
ثم التدرّج إلى **القاعدة النورانية** فالقرآن والتجويد والتحفيظ — بمساعدة الذكاء الاصطناعي.

المبدأ الأساسي: **لا يتجاوز الطفل الحرف حتى يُتقن نطقه** في كل حالاته (فتحة/ضمة/كسرة).

---

## الحالة الحالية (MVP)

هذه نواة أولى تعمل في المتصفح وتُثبَّت على الجوال (PWA)، قاعدة كود واحدة (React + TypeScript + Vite).

ما يعمل الآن:
- مرحلة **الحروف**: ٢٨ حرفاً × ٣ حركات بالترتيب، مع نظام بوابات (gating) يمنع التقدّم قبل إتمام الخطوة الحالية.
- عرض الحرف بالحركة، نموذج صوتي (TTS مؤقت)، تسجيل صوت الطفل، إعادة الاستماع.
- تلميحات المخرج للحروف الصعبة (ط ض ص ق ع ح ظ …).
- خريطة تقدّم وحفظ محلي (localStorage).
- طبقة **تقييم نطق قابلة للاستبدال** (`src/services/assessment.ts`).

ما هو مؤقت/قيد التطوير:
- **التقييم التلقائي الدقيق للنطق** هو أصعب جزء وأهمّه. حالياً يكتشف المحرّك المحلي
  "عدم وجود صوت/قصر المدة" فقط، ووليّ الأمر يؤكّد صحة النطق (parent-in-the-loop).
  الكشف الدقيق على مستوى المخرج (ط مقابل ت، ض مقابل د…) يحتاج نموذجاً صوتياً متخصصاً.

## المعمارية ونقاط التوسعة

```
src/
  data/curriculum.ts     الحروف، الحركات، المراحل (مصدر المنهج)
  services/
    recorder.ts          التقاط الصوت (MediaRecorder) — يعمل ويب/جوال
    assessment.ts        واجهة المقيّم + HeuristicAssessor + ServerAssessor
    progress.ts          منطق البوابات والحفظ المحلي
    speak.ts             النموذج الصوتي (TTS مؤقت)
  components/ screens/    الواجهة
```

نقطة ربط الذكاء الاصطناعي الحقيقي: `ServerAssessor` في `assessment.ts`.
اضبط `VITE_ASSESS_URL` على خدمة خلفية تُرجِع `{ pass, score, heard, message }`.
الواجهة تحوّل التسجيل تلقائياً إلى WAV (`src/services/wav.ts`) قبل الإرسال.

خدمة خلفية جاهزة موجودة في **`server/`** (FastAPI) بعدّة محرّكات:
- **التقييم السحابي بالذكاء الاصطناعي** عبر Azure Pronunciation Assessment (الأدقّ،
  درجة دقّة لكل فونيم، يدعم العربية) — يُفعّل بضبط مفتاح Azure.
- مقارنة **MFCC + DTW** مع مراجع صوتية محلية للحروف والحروف المتشابهة.
- تقييم طاقة احتياطي عند غياب المفتاح والمراجع.

التفاصيل وكيفية تفعيل Azure في `server/README.md`.

## خارطة الطريق

1. **الحروف** ✅ (نواة) — إتقان النطق المفرد بالحركات.
2. **محرّك التقييم بالذكاء الاصطناعي** — تمييز المخارج المتشابهة بدقة كافية لطفل
   (هذه النقطة تحسم جدوى الفكرة؛ يُنصح بإثباتها على ٤–٥ حروف صعبة أولاً).
3. **القاعدة النورانية** — الحروف المركّبة، المدود، التنوين، السكون والشدّة.
4. **القرآن والتجويد** — التلاوة، أحكام التجويد، والتحفيظ (الحروف مع كلمات).
5. **نقل إلى تطبيق أصلي** (React Native / Expo) مع إعادة استخدام المنطق والمنهج.

## الخصوصية (مهم — جمهور أطفال في أوروبا)

تسجيل أصوات الأطفال يخضع لقوانين صارمة (GDPR وحماية القاصرين). يجب من البداية:
- موافقة صريحة من وليّ الأمر قبل أي تسجيل.
- تقليل البيانات: المعالجة محلياً قدر الإمكان، وعدم تخزين التسجيلات افتراضياً.
- في حال إرسال الصوت لخادم، يكون مؤقتاً وللتقييم فقط مع حذف فوري وتشفير أثناء النقل.
